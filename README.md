# Skopelos Guide Web App

A responsive web application developed during my internship at Ontovisual as part of the Skopelos Guide project.

The application provides an interactive digital guide experience and integrates external services for authentication, dynamic content and map-based functionality.

## Features

- User authentication with Firebase Authentication
- Interactive maps using Leaflet
- Integration with REST APIs
- Dynamic content presentation
- Responsive user interface for different screen sizes

## Technologies

- React
- JavaScript
- HTML
- CSS
- Firebase Authentication
- REST APIs
- Leaflet
